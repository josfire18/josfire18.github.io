Big O Practice

The rules

  1. Total = passes × cost per pass. Count how many times a loop runs, then multiply by what each run does.
  2. Passes come from how the loop variable changes.
    Add or subtract a fixed amount (i+1, i-2) → walking → n
    Multiply or divide by a fixed amount (i*2, i//3) → jumping → log n
    Fixed count that never changes (range(10)) → 1
  3. One after another: add, keep the biggest. n + n² → n²
  4. Nested: multiply. A loop of n inside a loop of n → n²
  5. Drop constants and smaller terms. 3n² + 100n + 5 → n². Big O only cares about the shape of growth.
  6. Assume the worst case. A search that might stop early still counts as checking everything.
  7. Built-ins can hide loops. Ask: does this touch every item, or jump straight there? x in list looks like one step but it's a loop.
  8. log n = how many times you can halve n before hitting 1. 8 → 4 → 2 → 1 is 3 halvings, so log 8 = 3. A million is only about 20.
  9. Recursion: calls × work per call. Draw the call tree. One call each time works like a loop; two calls each time doubles every level.
